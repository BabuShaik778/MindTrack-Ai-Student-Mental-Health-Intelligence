# MindTrack-Ai-Student-Mental-Health-Intelligence


# 🧠 MindTrack AI #

MindTrack AI is an end-to-end Artificial Intelligence and Machine Learning platform designed to predict, monitor, and analyze student mental health risks using behavioral and lifestyle indicators. The system combines Machine Learning, Predictive Analytics, and Interactive Dashboards to help educational institutions identify at-risk students early and enable proactive intervention strategies.

## 🚀 Overview

Traditional student support systems are often reactive, identifying issues only after they significantly impact student well-being and academic performance.

MindTrack AI transforms student behavioral data into actionable insights through AI-driven predictive analytics, enabling institutions to move from reactive monitoring to proactive decision-making.

## 🤖 Artificial Intelligence & Machine Learning Pipeline

### Data Collection

The system analyzes multiple student-related factors:

* Age
* Gender
* Education Level
* Stress Level
* Sleep Duration
* Screen Time
* Physical Activity
* Exam Anxiety

### Feature Engineering

Custom engineered features:

* Stress-Sleep Interaction
* Screen Time–Physical Activity Interaction
* Numerical Stress Encoding

### Data Preprocessing

* Data Transformation Pipeline
* Feature Encoding
* Data Standardization
* Input Validation

### Machine Learning Model

**Algorithm Used:** Random Forest Classifier & Logistic Regression

### Model Evaluation Metrics

* Accuracy Score
* Precision Score
* Recall Score
* F1 Score

### Prediction Workflow


Student Input
      ↓
Feature Engineering
      ↓
Data Preprocessing
      ↓
Random Forest Model
      ↓
Risk Probability
      ↓
Risk Classification
      ↓
Dashboard Visualization
